# Сайт-визитка — Алексей Манахов

Одностраничный сайт-визитка менеджера образовательного проекта. Чистая статика, без сборки
и зависимостей: открыть `index.html` в браузере — уже работает.

## Как опубликовать на GitHub Pages

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
2. Branch: `main`, папка `/ (root)`. Save.
3. Через пару минут сайт живёт на `https://alexym1988.github.io/CV/`.

Файл `.nojekyll` в корне обязателен — без него GitHub Pages прогоняет сайт через Jekyll
и может выкинуть служебные файлы.

**Про `robots.txt`.** Поисковики читают его только из корня домена
(`https://alexym1988.github.io/robots.txt`), а не из подпапки. Пока сайт живёт по `/CV/`,
файл лежит здесь про запас и ни на что не влияет; `sitemap.xml` в этом случае отправляется
вручную через Яндекс.Вебмастер и Google Search Console. После переименования репозитория
в `alexym1988.github.io` оба файла заработают сами.

**Короткий адрес.** Если переименовать репозиторий в `alexym1988.github.io`, сайт откроется
по адресу `https://alexym1988.github.io/` без `/CV/`. Тогда нужно поправить абсолютные пути
в `index.html` (`canonical`, `og:url`, `og:image`), в `404.html`, `robots.txt` и `sitemap.xml`.
Свой домен подключается там же в Settings → Pages → Custom domain.

## Структура

```
index.html      вся страница: разметка, мета-теги, JSON-LD
styles.css      стили, светлая и тёмная темы, версия для печати
script.js       переключатель темы, липкая шапка, раскрытие кейса по ссылке, печать
fonts/          Golos Text и Inter, подмножества cyrillic + latin, самохост
assets/         favicon.svg, apple-touch-icon.png, og.png
404.html        страница «не найдено»
.nojekyll       отключает обработку Jekyll на GitHub Pages
robots.txt      индексация разрешена, ссылка на sitemap
sitemap.xml     одна страница
```

## Как обновлять

**Текст.** Всё содержимое лежит прямо в `index.html` — редактируется как обычный текст.
Секции подписаны комментариями вида `<!-- ===== КЕЙСЫ ===== -->`.

**Новый кейс.** Скопировать блок `<article class="case" id="case-...">`, поменять `id`,
номер в строке `case__label`, заголовок, контекст, чипы с цифрами и содержимое. По `id`
на кейс можно дать прямую ссылку: `.../CV/#case-gov-650` — он раскроется сам.

Структура кейса важна: тизер (лейбл, заголовок, контекст, цифры) лежит **снаружи**
`<details>`, а внутрь уходит только раскрывающаяся часть. Внутри `<summary>` по спецификации
HTML допустим лишь фразовый контент — `<span>` и `<svg>`, но не `<p>` и не заголовки.
Если положить туда абзацы, скринридер прочитает всю карточку как имя одной кнопки,
а заголовок кейса выпадет из иерархии.

Не забудьте про текст в `<span class="sr-only">` внутри `summary`: без него на странице
получится шесть кнопок с одинаковым именем «Как это было».

**Цифры на первом экране.** Блок `<section class="metrics">`. У каждой плитки три строки:
значение, подпись и обязательная третья строка контекста — где, на каком объёме и когда.
Цифру без базы на сайт не ставим: она читается как выдумка.

**Дата обновления.** Правится в трёх местах: `footer__upd` в `index.html`, `dateModified`
в JSON-LD там же и `lastmod` в `sitemap.xml`.

**Кэш стилей.** После правки `styles.css` или `script.js` увеличить номер в `?v=2` у
соответствующего `<link>` и `<script>` в `index.html` (и в `404.html`), иначе у посетителей
останется старая версия.

## Правила содержания

Сайт построен на одном принципе: **ни одной цифры, за которую нельзя отвечать на собеседовании.**

- Публичные данные о работодателе (лицензия, партнёры, «более 1000 обученных», «16 регионов»)
  лежат в отдельной приглушённой карточке «О проекте · публичные данные» с подписью об источнике.
  Они никогда не попадают в полосу метрик и не соседствуют с «я»: это характеристика места работы,
  а не личный результат.
- У каждой личной метрики есть база и период: не «+21%», а «+21% по 10 ключевым курсам,
  Контур.Школа, 2018–2024».
- Название госзаказчика не раскрывается — в кейсе стоит отдельная строка об этом.

## PDF-резюме

Отдельного файла с резюме в репозитории нет намеренно: он устаревает и содержит телефон
и дату рождения. Вместо этого кнопка «Сохранить страницу в PDF» вызывает печать, а `@media print`
в `styles.css` готовит аккуратный A4: светлая тема, все кейсы раскрыты, шапка и кнопки скрыты,
в подвале — почта, Telegram и адрес сайта.

## Картинка для превью ссылки

`assets/og.png` (1200×630) показывается, когда ссылку кидают в Telegram или мессенджер.
Если меняются цифры на первом экране, картинку стоит перерисовать, чтобы она не расходилась
со страницей.
